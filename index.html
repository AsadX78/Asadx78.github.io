HighImmunefi — Threshold Network2026

Subdomain takeover via dangling Google Cloud Storage bucket

Discovered a live DNS record pointing to a deleted GCS bucket (NoSuchBucket), allowing arbitrary content hosting on a trusted *.threshold.network subdomain. Validated with three independent proofs (HTTP response, GCS JSON API, custom-domain Host-header mapping). Responsibly reported with a read-only PoC — no resources were claimed.
